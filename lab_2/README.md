# Отчёт по лабораторной работе №2
**Дисциплина:** Математические основы баз данных
**Тема:** Базовые SQL-запросы и фильтрация данных (на примере БД маркетплейса)

---

## 1. Цель работы

Освоить базовые средства выборки данных в PostgreSQL: структуру команды `SELECT`, фильтрацию `WHERE`, предикаты `BETWEEN`/`IN`/`LIKE`/`IS NULL`, сортировку `ORDER BY`, постраничный вывод `LIMIT`/`OFFSET`, устранение дубликатов `DISTINCT`, а также наполнение таблиц согласованными тестовыми данными с помощью `generate_series`.

---

## 2. Постановка задачи (по пособию)

1. Наполнить все таблицы согласованными данными, для массового заполнения использовать `generate_series`; в крупные таблицы (товары, заказы) — не менее 1000 строк.
2. Запрос с `DISTINCT` и псевдонимами столбцов.
3. Запрос с фильтрацией по нескольким условиям через `AND`/`OR` со скобками.
4. Применить предикаты `BETWEEN`, `IN`, `LIKE` (или `ILIKE`) и `IS NULL` — каждый хотя бы раз.
5. Сортировка по двум столбцам в разных направлениях.
6. Постраничный вывод через `LIMIT`/`OFFSET`.
7. Для каждого запроса привести текст, назначение и фрагмент результата.

Полный скрипт — в файле [`lab2_requests.sql`](./lab2_requests.sql). Скрипт воспроизводим: начинается с `TRUNCATE ... RESTART IDENTITY CASCADE`, выполняется повторно без ошибок (проверено двукратным прогоном в PostgreSQL 18.6).

## 4. Запросы на выборку и фильтрацию

### Задание 2. Столбцы без дубликатов (`DISTINCT`, псевдонимы)

Назначение: вывести заданные столбцы товаров без полных дубликатов, переименовав их через `AS`.

```sql
SELECT DISTINCT
    category_id AS "Код категории",
    price AS "Цена (руб.)",
    description AS "Описание"
FROM products;
```

Результат: 1000 строк. Фрагмент:

```
 Код категории | Цена (руб.) |      Описание
---------------+-------------+---------------------
             5 |     9898.00 | Описание товара 554
             5 |      848.00 | Описание товара 904
             3 |     9714.00 | Описание товара 622
```

### Задание 3. Несколько условий с `AND`/`OR` и скобками

Назначение: активные товары с ценой вне диапазона 1000–5000. Скобки фиксируют приоритет `OR` внутри `AND`.

```sql
SELECT title AS "Наименование", description AS "Описание", price AS "Цена (руб.)"
FROM products
WHERE is_active AND (price < 1000 OR price > 5000);
```

Результат: 539 строк. Фрагмент:

```
 Наименование |     Описание      | Цена (руб.)
--------------+-------------------+-------------
 Ноутбук 1    | Описание товара 1 |      637.00
 Наушники 2   | Описание товара 2 |      774.00
 Клавиатура 3 | Описание товара 3 |      911.00
```

### Задание 4. `IN`, `BETWEEN`, `ILIKE`, `IS NULL`

Назначение: товары из нечётных категорий в ценовом диапазоне, с описанием, кроме телефонов (поиск без учёта регистра).

```sql
SELECT id, title, category_id, price, description
FROM products
WHERE category_id IN (1, 3, 5, 7, 9) AND price BETWEEN 500 AND 35000 AND description IS NOT NULL
    AND title NOT ILIKE '%Телефон%';
```

Результат: 400 строк. Фрагмент:

```
 id |   title    |  price
----+------------+---------
  2 | Наушники 2 |  774.00
  4 | Товар 4    | 1048.00
  6 | Товар 6    | 1322.00
```

Замечание: столбец `products.description` объявлен `NOT NULL`, поэтому условие `IS NOT NULL` здесь всегда истинно — предикат применён формально. Для содержательной демонстрации `IS NULL` лучше подходит nullable-столбец, например `reviews.comment` (`WHERE comment IS NULL`).

### Задание 5. Сортировка по двум столбцам в разных направлениях

Назначение: адреса, отсортированные по убыванию `id` и возрастанию `house` (направление `ASC` по умолчанию).

```sql
SELECT id, city, street, house
FROM addresses
ORDER BY id DESC, house;
```

Результат: 100 строк. Фрагмент:

```
 id  |      city       |  street   | house
-----+-----------------+-----------+-------
 100 | Санкт-Петербург | Улица 100 | 1
  99 | Москва          | Улица 99  | 100
  98 | Казань          | Улица 98  | 99
```

### Задание 6. Постраничный вывод (`LIMIT`/`OFFSET`)

Назначение: вторая страница товаров по 5 записей (пропустить 5, взять 5).

```sql
SELECT id, title, price
FROM products
ORDER BY id ASC
LIMIT 5 OFFSET 5;
```

Результат: 5 строк.

```
 id |   title    |  price
----+------------+---------
  6 | Товар 6    | 1322.00
  7 | Товар 7    | 1459.00
  8 | Товар 8    | 1596.00
  9 | Товар 9    | 1733.00
 10 | Телефон 10 | 1870.00
```
