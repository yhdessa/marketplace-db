# Лабораторные работы по дисциплине "Математические основы баз данных"

Данный репозиторий содержит материалы по выполнению лабораторных работ, посвященных проектированию и реализации базы данных для **маркетплейса**.

---

## 📁 Структура репозитория

Каждая лабораторная работа находится в отдельной директории (например, `lab1/`, `lab2/` и т.д.) со следующей типовой структурой:

* **`README.md`** — отчёт по лабораторной работе (теоретическое обоснование, ход работы, результаты)
* **`*.sql`** — DDL/DML-скрипты базы данных (создание схемы, ограничения, функции, запросы)
* **`*.png`** — схемы, графики и ER-диаграммы (при наличии)
